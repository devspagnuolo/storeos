# Roadmap

## MVP operacional (0–12 semanas)

1. Fundação: tenancy, RBAC, auditoria, catálogo, estoque, storefront e Docker.
2. Venda: carrinho persistente, checkout guest, CEP, PIX/cartão, pedido, e-mails transacionais.
3. Operação: OMS com timeline, Bling (produtos/estoque/pedidos), Correios/Melhor Envio e dashboard.
4. Go-live: observabilidade, backup/restore, pentest, LGPD, performance e runbooks.

## Enterprise (3–9 meses)

Marketplace, multi-CD, assinatura, regras avançadas de promoção, CRM 360, CMS visual, automação multicanal, loyalty, busca semântica, data warehouse e IA com RAG isolado por tenant.

## Métricas de sucesso

Disponibilidade 99,9%; p95 API < 300 ms para consultas; zero dados de cartão armazenados; sincronização ERP com sucesso > 99,5%; taxa de conclusão de checkout e conversão acompanhadas por tenant.
